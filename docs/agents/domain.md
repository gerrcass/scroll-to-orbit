# Domain docs

Single-context repo.

## Before exploring

- Read `GLOSSARY.md` at the repo root.
- Read the ADRs in `docs/adr/` that touch the area you are about to change.
- Read `docs/discovery/grill-session.md` for the objective and the story decisions.

If a file does not exist, proceed silently.

## Use the glossary's vocabulary

Name concepts as `GLOSSARY.md` does. If the concept you need is missing, note the gap rather than inventing a synonym.

## Flag ADR conflicts

If a change contradicts an ADR, surface it explicitly in the PR and in the review rather than silently overriding it. Reopen the decision only with a written reason.
